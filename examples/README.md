# ShowKit examples

`gallery/` is the source for the public GitHub Pages selector. It presents the
three published demos from the ShowKit website: Airbnb travel search, a
text-redacted Linear Agent project-and-todo flow, and text-redacted Stripe
payment tools. The
gallery keeps those published URLs as the single source. It does not copy their captured
third-party images or fonts into this MIT-licensed repository.

`product-insights/` is a complete static demo generated by ShowKit from
`fixtures/demo-apps/public/public.demo.ts`.

The source app, people, workspace, sessions, dates, and metrics are synthetic.
This example uses three steps because that is the useful sequence for this
flow. ShowKit chooses a flow-appropriate step count instead of forcing every
demo to use five steps.

The checked output contains semantic HTML, selectable text, one local
content-addressed fixture image, zero full-scene raster files, and zero remote
requests. `artifact.json`, `quality.json`, and `verification.json` record the
source and checks used for this build.

The public repository keeps this self-contained example as a checked fixture.
Regenerate it only from the public fixture, then review the complete diff and
rerun the release gate before replacing the checked output.
